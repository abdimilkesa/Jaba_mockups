# JABA MOCKUPS

A platform for discovering and downloading high-quality design mockups.

## About

JABA MOCKUPS is a web platform where designers can browse, preview, and download realistic mockups for their design projects.

## Technologies

- React
- Node.js
- Express.js
- MongoDB
